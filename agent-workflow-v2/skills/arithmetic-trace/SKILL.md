---
name: arithmetic-trace
description: Measure a bounded chain of JavaScript binary64 arithmetic without mental simulation.
---

Prepare and run this skill for a concrete numeric uncertainty. Supply an initial
number, a short list of arithmetic operations and a repeat count. The native
script returns each measured value, its 17-digit representation and sign.
It cannot import or execute project code. Use the trace to choose a focused
diagnostic in the declared test file; it is not proof of application behavior.
